# 🛒 ShopSphere - E-Commerce Website

A modern and responsive E-Commerce web application built with **React.js**, **Redux Toolkit**, **React Router**, and **Axios**. Users can browse products, manage their cart and wishlist, authenticate securely, and place orders.

---

## 🚀 Features

- User Authentication (Login / Register)
- Browse Products
- Product Search & Filtering
- Product Details Page
- Add to Cart
- Wishlist Management
- Checkout Process
- Order Management
- Protected Routes
- Responsive Design
- Global State Management with Redux Toolkit
- API Integration with Axios
- Error Handling & Loading States

---

## 🛠️ Tech Stack

### Frontend

- React.js
- Redux Toolkit
- React Router DOM
- Axios
- Tailwind CSS / CSS

### Backend

- Express.js

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/shopsphere.git
```

### Navigate to Project

```bash
cd shopsphere
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

---

## 🌐 Environment Variables

Create a `.env` file in the root directory.
